Директория с экспериментами (по умолчанию - [experiments](./experiments)) содержит в себе информацию о проводимых экспериментах: их конфигурации обучения и промежуточные состояния обучения моделей. Импортировать и экспортировать эксперименты в(из) локальную(ой) директорию(и) с экспериментами можно с помощью внешнего хранилища, которое реализовано для работы с Google Диском в [external_storage](./external_storage).

Ожидаемый сценарий добавления новой конфигурации:
- модифицируется *активная* конфигурация обучения (`config/run_experiment.py`)
- эта конфигурация сохраняется в локальную директорию с экспериментами (`ExperimentsStorage::save_config()`)

Для запуска настроенного эксперимента достаточно запустить простой Python-скрипт [run_pipeline.py](./run_pipeline.py).

## Виртуальная сетка 2,5 см → GNN

Архитектура встроена в существующий пайплайн: `run_pipeline.py` →
`config/run_experiment.py` → `GAN`, `GanTrainer`, `WganEpochTrainer`, `Stepper`.
Логгеры, сохранение экспериментов и формат `training_checkpoint` прежние.
Запуск из `GAN_project`: `python run_pipeline.py`. Зависимости — существующий
`requirements.txt`; отдельный trainer и отдельное окружение не требуются.

Генератор принимает нормальный шум `[B,64]` и условия. Их общий вектор
распространяется по полной карте `[H,W]` и сразу объединяется с шестью каналами
геометрии. Начальной карты 4×4, интерполяции и увеличения разрешения нет.
Входная свёртка формирует 64 канала, затем идут три остаточных блока:
`Conv3×3(d=1) → SiLU → Conv3×3(d=1)`,
`Conv3×3(d=2) → SiLU → Conv3×3(d=1)`,
`Conv3×3(d=4) → SiLU → Conv3×3(d=1)`.
После каждого блока: `SiLU(h + block(h))`. Все свёртки сохраняют `[H,W]`.
Выход: `Conv3×3 → SiLU → Conv1×1 → Softplus → маска`.
Для значений по умолчанию пространственное рецептивное поле выходной позиции
составляет 25×25 ячеек (62,5×62,5 см), включая входную/выходную свёртки;
общие шум и условия при этом доступны каждой позиции.
`dilation_rates=(1,2,4)` задаются в `config/run_experiment.py`.
CNN выдаёт неотрицательную плотность на сетке 2,5 см, матрица площадей пересечений
агрегирует её в физические энергии `[B,54,10]`. Размеры виртуальной карты
вычисляются из геометрии. Критик — четыре блока edge-aware GNN по физическим
модулям с рёбрами по общим границам. REAL не дробится на виртуальные ячейки.

В `WganEpochTrainer` добавлены параметры `physical_modules` и `lambda_gp`:
для новой конфигурации GP=10 по физическим энергиям с маской слоёв;
дополнительные потери адаптированы к физическим энергиям `[B,54,10]`,
с масками отсутствующих слоёв. Координатная `conditional_energy_loss` удалена.
Прежний формат индексной сетки поддерживается оставшимися потерями. Adam lr=1e-4,
betas=(0,0.9), n_critic=5. Сеточные `PhysicsDataStatistics` отключены в активной
конфигурации; совместимая `CriticValuesDistributionMetric` остаётся.

В `global_config.paths.data_dir_path` нужен NPZ, путь к которому, как раньше,
задаётся в `form_dataset`: `EnergyDeposit[N,7,9,10]`, `ParticlePoint[N,3]`,
`ParticleMomentum[N,3]`, `ParticlePDG[N]`. Также поддерживается физический формат
`EnergyDeposit[N,54,10]` с `ModuleIds[54]`.

Активная конфигурация явно выбирает `data.fhcal_geometry_report_19()`: координаты,
маски и карта ID→[row,col] находятся в существующем `pipeline/data.py`.
Отдельные `fhcal_geometry.json` и `fhcal_module_map.json` для этого варианта
больше не нужны. Проверка коллизий, пустых позиций, энергии отсутствующих слоёв
и сохранения энергии при конверсии остаётся включённой.

Данные из отчёта `fhcal_check_report.txt` для `мюоны/19`:

- ID 1..34: **7** записанных слоёв; ID 35..54: **10**. Маска не определяется
  последним ненулевым сигналом: даже у полностью нулевого модуля №1 есть 7 слоёв.
- Координата центров Z = 202.22000122070312; это не объявляется передней плоскостью.
- Карта хранения: №8→[1,4], №16→[3,6], №19→[3,2]; все 54 позиции уникальны.
- Для выбранных размеров: H×W=42×62, 2504 активных XY-ячеек, 204 направленных
  ребра, один связный граф. Формулы агрегации и правило соседства менять не нужно.
- Размеры 15/20 см и единицы см остаются предположениями выбранной архитектуры:
  сам отчёт их независимо не измеряет.

`fhcal_data_muons_19.npz` проверен относительно 120000 ROOT-событий: 119999
ненулевых событий, энергии и условия совпали. Настройка имени входного файла
`fhcal_data_muons_81619.npz` сохранена. **Составной набор 81619 отчётом не проверен**:
для него этот снимок подходит только при той же геометрии, карте и числе слоёв
в источниках 8/16/19. Для проверки отдельного набора №19 поменяйте только имя NPZ
в `form_dataset`. Для другой конфигурации можно использовать прежние
`load_geometry()`/JSON-карту или явно задать свою геометрию; автоматического
угадывания по индексам NPZ нет.

Условия: `(x0,y0,z0,px,py,pz)`, стандартизованные по train, плюс one-hot PDG.
Train/validation split использует прежний seed; статистики train одинаковы
при обоих вызовах `form_dataset`. Для inference статистики и словарь PDG
сохраняются в буферах генератора `condition_mean`, `condition_scale`, `pdg_codes`.
ParticlePoint — вершина генерации, не точка попадания.

Новый `model_name='physics_virtual25_dilated_gnn_layers7_10'` отделяет прежние
чекпойнты, которые могли содержать другие маски слоёв/геометрию, и старые CNN. После начала обучения сохраняйте те же данные, геометрию и карту
при resume. Существующие классы CaloganPhysicsGenerator3D, CaloganPhysicsDiscriminator3D
и PhysicsDataset теперь содержат новую реализацию; общие классы пайплайна сохранены.
Вычисления всех блоков идут на полном разрешении: расход памяти зависит от
`H,W` и batch size. Полное обучение требует проверенной реальной геометрии. Softplus сам по себе
не решает воспроизведение строгих нулей; виртуальная карта не является
подтверждённой реконструкцией распределения энергии внутри модуля.

Код размещён в прежних файлах:

- `pipeline/generators.py`: `CaloganPhysicsGenerator3D` — виртуальная CNN и агрегация.
- `pipeline/discriminators.py`: `CaloganPhysicsDiscriminator3D` и `MessageBlock` — GNN-критик.
- `pipeline/data.py`: `ModuleGeometry`, `PhysicalGeometry`, загрузка геометрии,
  конверсия NPZ, `ConditionEncoder`, `PhysicsDataset`, `get_physics_dataset`.
- `pipeline/train.py`: gradient penalty и существующий цикл WGAN-GP.
- `config/run_experiment.py`: выбор моделей и параметров.



### Дополнительные потери генератора

Для физического формата `expm1` не применяется. Области согласованы с геометрией:
центр — модули 15×15 см; лево/право — модули 20×20 см по X относительно середины
центральных модулей. Продольные потери учитывают все существующие слои области.

- `energy_loss`: квадрат разности средних полных энергий батчей. FAKE не
  сопоставляется поэлементно отдельному REAL; это перенос прежней энергетической
  цели на статистику, а не требование совпадения случайных событий.
- `sparsity_loss`: прежний L1 для `log1p(E)`, усреднённый только по существующим
  модульным слоям. Это штраф за амплитуду, не прямое совпадение долей точных нулей.
- `layer_fraction_losses`: сравнение отсортированных распределений долей энергии
  по слоям отдельно для центра/лева/права; нулевые события дают нулевые доли.
- `quantile_energy_loss`: прежние взвешенные квантили `log1p` полной энергии.
- `peak_concentration_loss`: квантили долей энергии в top-1/3/5 физических модулях,
  после суммирования их продольных слоёв. Большие и малые модули сравниваются
  по полной энергии, не по плотности.
- `layer_distribution_loss`: W1 между распределениями `log1p` абсолютной энергии
  каждого существующего слоя в трёх областях.

Веса возвращены к исходным: layer_fraction=0.5, quantile=0.04, peak=0.1,
layer_distribution=0.5; energy=0 и sparsity=0, как раньше. Последние две потери
вычисляются и логируются, но при нулевом весе не влияют на обучение.
Веса требуют проверки на реальных данных после смены архитектуры.
Условия частицы остаются входами обеих сетей; удалена именно координатная потеря.
GP=10 сохранён для WGAN-GP. `lambda_gp=0` отключает его; для обучения без GP
нужно отдельно выбрать другой способ ограничения критика (например, спектральную
нормализацию). Дополнительные потери генератора не заменяют ограничение критика.
Для геометрии с исправленными масками выбрано имя `physics_virtual25_dilated_gnn_layers7_10`,
чтобы не загружать автоматически прежний эксперимент. Веса задаются в
`config/run_experiment.py`.
